# 🎒 國文會考魔法寫作小幫手

給**國小四年級**學生使用的「先說後寫」作文練習系統：孩子先用說的或打字的方式把事情講出來，
AI 蘇格拉底式提問兩個引導問題，最後產出符合國中會考架構的完整作文與 K/C 診斷卡。

## ▶️ 線上直接使用

**<https://joshua19683721.github.io/writing_system_framework>**

開啟後按右上角「⚙️ 設定」貼上自己的 Groq API Key（<https://console.groq.com/keys> 免費申請）即可開始，
不需要安裝任何東西。

> 想離線使用或自行架站，下載 `index.html` 直接用瀏覽器開啟即可。

## 🚀 快速開始

1. **申請 Groq API Key**（免費）→ <https://console.groq.com/keys>
2. **開啟 `index.html`**（建議見下方「本機伺服器」）
3. 按右上角 **「⚙️ 設定」** → 貼上 Key → 按「儲存」
4. 選一個練習主題 → 用麥克風說出來或打字貼上 → 一路按下一步就完成了

---

## 🖥️ 建議用本機伺服器開啟

直接雙擊（`file://`）通常可以運作，但**語音輸入**在部分瀏覽器會被限制。用本機伺服器最穩：

```bash
cd writing_system_framework
python -m http.server 8000
```

然後開啟 <http://localhost:8000/index.html>

> 需要 Node.js 的話也可以用 `npx serve .`

## 📖 使用流程

| 步驟 | 孩子要做的事 | 系統做什麼 |
|---|---|---|
| **Step 1** 選主題 + 口述 | 選主題，按麥克風說故事，或直接打字 | 自動存草稿到瀏覽器，關掉頁面也不會遺失 |
| **Step 2** 導師提問 | 回答兩個引導問題（可只答一個，也可都不答） | Node 1 產生「五感／心理細節」+「轉折／因果關係」兩題；不滿意可要求換題 |
| **Step 3** 診斷卡 + 定稿 | 閱讀 Keep／Change 建議，複製或列印文章 | Node 2 & 3 重建會考架構文章，並標示字數是否落在 400～600 字 |

每一步都有 **⬅️ 返回上一頁**，隨時可以回去改。

## 🇹🇼 繁體中文保證

畫面上的中文**一律是繁體中文（台灣用字）**，由兩層機制共同把關：

| 層次 | 做法 |
|---|---|
| **1. Prompt 層** | 兩份 System Prompt 都明文要求「不得出現任何簡體字」，並附上台灣用字對照表（学习→學習、软件→軟體、网络→網路、数据→資料、视频→影片…） |
| **2. 程式層** | 所有從模型回傳的欄位（讚美、引導問題、placeholder、Keep、Change、成稿）在顯示前一律經過 `toTraditional()` 轉換 |

程式層內建 **1157 組逐字對照** ＋ **60 組台灣慣用詞**，即使模型不聽話、或孩子用簡體字口述，畫面上也不會出現簡體字。

> 詞彙替換例：`软件`→`軟體`（非 `軟件`）、`网络`→`網路`（非 `網絡`）、`数据`→`資料`（非 `數據`）、`视频`→`影片`（非 `視頻`）。

回歸測試第 13、14 組專門驗證這件事（含簡體輸入必須無殘留）。

## 🔒 隱私

- API Key 只存在**這台電腦的瀏覽器 localStorage**，不會上傳到任何伺服器，也沒有後端。
- 孩子的作文內容同樣只留在本機，除非使用者自己按「複製」或「列印」。
- **公用電腦請用完按「⚙️ 設定 → 清除」**，並關閉分頁。

> 補充：這是設計給老師／家長在自己或可信任的裝置上使用的工具。若要多人共用，
> 建議改為後端代理模式並把 Key 放在伺服器端環境變數。

## 🩺 疑難排解

| 症狀 | 原因 | 怎麼辦 |
|---|---|---|
| 按了沒反應跳出「Groq 伺服器暫時有問題」 | 伺服器忙碌或連線中斷 | 系統已自動重試 3 次；按錯誤框上的「🔄 再試一次」 |
| 「API Key 不正確或已過期」 | Key 貼錯或已失效 | 到設定重新貼上新的 Key |
| 「找不到這個模型」 | 模型名稱已下架 | 到設定換一個，預設 `llama-3.3-70b-versatile` |
| 「請求太頻繁或免費額度用完」 | Groq 免費額度用完 | 稍後再試，或到 console.groq.com 檢查額度 |
| 麥克風按鈕不見了 | 瀏覽器不支援 Web Speech API | 用 Chrome／Edge 開啟；其他瀏覽器請改用打字 |
| 麥克風沒反應 / 顯示「權限被拒絕」 | 瀏覽器未授權麥克風 | 點網址列的權限圖示允許麥克風；建議改用 `http://localhost` |
| 頁面長得怪怪的、沒套用樣式 | 阻擋了 Tailwind CDN | 需連網；若要離線使用，把 Tailwind CSS 下載成本機檔案 |

## 🛠️ 自訂

所有設定都在 `index.html` 裡，用任何文字編輯器就能改：

| 想改什麼 | 位置 |
|---|---|
| 練習主題 | 搜尋 `data-topic=` 的四個按鈕 |
| 引導問題的規則 | 搜尋 `PROMPT_NODE1` |
| 診斷與改寫規則 | 搜尋 `PROMPT_NODE23` |
| 預設模型、逾時時間、重試次數 | 搜尋 `var CONFIG =` |
| 建議字數範圍（預設 400～600） | 搜尋 `n >= 400 && n <= 600` |

改完後跑一次測試確認沒弄壞：

```bash
node test/app.test.js
```

## 🧪 測試說明

`test/app.test.js` 用一個極小的 DOM shim 在 Node 的 `vm` 沙箱中執行 `index.html` 內的腳本，
並用假的 `fetch` 模擬 Groq 回應，覆蓋：

- 完整三步流程、Prompt 組裝、兩次 API 呼叫各只發一次
- 模型回傳 ``` 包圍、前導廢話、字串陣列、物件陣列、欄位缺漏等異常格式
- HTTP 401／429／5xx、逾時、重試與自動降級（不支援 `response_format` 的模型）
- 未設定 API Key 時完全不會發出請求
- 模型輸出含 HTML 時以純文字渲染（XSS 防護）
- HTML 與 JS 的 id 關聯一致性（36 個引用／44 個定義）
